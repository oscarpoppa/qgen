{# math buttons above the question box (problem_form.js inserts them). In each pattern "@" is the selected text (or where it goes) and "¶" is where the cursor ends up. #} {% from "_macros.html" import tip %} {% set tip_math %}

The buttons write math the page shows as real formulas. Select something first to put it inside, e.g. select x+1 and press √.

  • \( x^2 \) → x²
  • \( \sqrt{[a]} \) → square root of each student's number
  • \( \frac{[a]}{[b]} \) → a fraction
  • \( [a]x^2 + [b]x + [c] \) → a quadratic, signs tidied (+ −3 shows as − 3)

Math sits between \( and \); the buttons add those when needed. Values in [brackets] work inside math too.
