The answer is worked out from each student's values, so it's written as a formula, not as display math. The buttons write it for you; select something first to put it inside, e.g. select [a] and press √.

  • [a]^2 → a squared
  • sqrt([a]) → square root
  • ([a])^(1/3) → cube root
  • pi * [r]^2 → π r²
  • abs([a] - [b]) → distance between them
  • round([a] / 3, 2) → rounded to 2 places
  • sqrt([a]), -sqrt([a]) → two answers (±): separate them with a comma

To show students the answer as 2√3 rather than 3.4641, fill in “Show the correct answer as” below.
