Describe it the way you'd tell a colleague. Claude fills in the form below, then you check it.

Nothing is saved, and students see nothing, until you press Save problem.

Each click costs a few cents; you can use it 30 times an hour.

{% endset %} {% set tip_ai_problem %}

Say what kind of question, what changes from student to student, and what's being asked. For example:

  • A pick-one question adding two different whole numbers from 1 to 20
  • True or false: a random number from 1 to 50 is bigger than another one
  • Short text: the capital of a random country from France, Japan and Brazil

It fills in the type, question, values and answer.

{% endset %} {% set tip_ai_values %}

Use this when you'll write the question yourself and only want help with the random values. It fills in the Random values table and leaves everything else alone.

  • two different numbers under 20
  • a price between $2 and $20 in quarters
  • a random first name
  • a decimal from 1 to 10 with 2 places

No square brackets needed here: plain English is fine.

{% endset %} {% set tip_qtype %}

How students answer, and how it's marked:

  • Numeric: they type a number. Marked instantly.
  • Short text: a word or phrase; any answer on your list counts.
  • Pick one: round buttons, one right choice.
  • Pick several: tick boxes; they must tick exactly the right ones.
  • True / False: the right answer can depend on the values, like a > b.
  • Long text: an essay you grade yourself, with partial credit, highlights and comments.

Everything except Long text is scored automatically.

{% endset %} {% set tip_title %}

A short name so you can find this problem in your lists and in the quiz builder.

Students never see it; they see the quiz's title.

{% endset %} {% set tip_question %}

What the student reads. Put a value's name in square brackets and every student sees a randomly picked number or word:

A train goes [speed] mph for [hours] hours.

Math works inside the brackets too: [speed * 2], [round(a / b, 2)], [sqrt(n)].

Brackets without a value name, like [0, 5], are shown just as typed.

The chips under this box insert your value names for you.

Math that looks like math: put it between \( and \). \( [a]x^2 + [b]x + [c] \) shows as a real formula, with each student's numbers. For Numeric problems, the math buttons above the box write this for you, and the preview under the box shows how it will look.

{% endset %} {% set tip_values %}

Each value is drawn fresh for every student, so students can't copy each other's answers.

Give each value a name, choose its kind, and fill in the settings. Then use [name] in the question, answer and choices.

Show me 3 examples at the bottom shows you what three different students would get.

{% endset %} {% set tip_name %}

A short word: letters and digits, starting with a letter, no spaces, like speed, a, who, x2.

Capitals matter: Speed and speed are different names.

For matched pairs from a list, name both columns: country = capital with items France = Paris, Japan = Tokyo.

{% endset %} {% set tip_kind %}
  • Whole number: from–to, optionally in steps, optionally never zero.
  • Decimal: from–to, with a number of decimal places (1 if left empty).
  • Pick from list: one item from your list, or several different ones.
  • Calculated: worked out from other values, like speed * hours.
  • Imaginary / Complex: only for complex-number problems.
{% endset %} {% set tip_settings %}

The boxes change with the kind; the grey line under them explains what they do.

not zero skips 0, handy when you divide by the value.

different from: other value names this one must never equal, separated by commas, without brackets, e.g. a, b. Only one of each pair needs it.

{% endset %} {% set tip_choices %}

One choice per line. Put * in front of each correct one:

*[a + b]
[a + b + 1]
[a * b]

Wrong choices built from the values (like [a + b + 1]) stay believable for every student. Use Show me 3 examples to check that no two choices ever come out the same.

{% endset %} {% set tip_combos %}

Only for questions where more than one set of ticks is right, like “tick two numbers that add up to 10”.

Leave the * off, and write each right set on its own line, choices separated by commas, exactly as in the list above:

[a], [10 - a]
[b], [10 - b]

{% endset %} {% set tip_shuffle %}

Each student gets the choices in a different order, so “it's the second one” doesn't help anyone.

{% endset %} {% set tip_show_n %}

Show each student only some of the choices, e.g. 4 out of 8, so students see different options.

At least one correct choice is always included. Leave it empty to show them all.

{% endset %} {% set tip_precision %}
  • Within 0.01: 3.14 counts for 3.14159 (for numbers under 1, within 1%). Best for most problems.
  • Exactly: must match to 4 decimal places.
  • Rounded to 2 decimal places: they must round, e.g. 3.14.
  • Rounded to a whole number: they must round, e.g. 3; 6.5 rounds to 7.
{% endset %} {% set tip_display %}

The answer box above is worked out as a number, so results show e.g. 3.4641. Write the exact form here to show it too: results then say \( 2\sqrt{3} \) (≈ 3.4641).

Use the same [values] as the question, e.g. \( \frac{[a]}{[b]} \) or \( [a]\sqrt{[n]} \). Students are graded on the number either way, and may type math themselves, like 2√3.

{% endset %} {% set tip_ordered %}

For an answer with several numbers, like r1, r2:

  • Off: 3, 5 and 5, 3 both count. Right for roots or "the two numbers".
  • On: they must be in your order. Right for a point (x, y).

Answers with a single number aren't affected.

{% endset %} {% set tip_complex %}

Leave this off for ordinary arithmetic: then a square root of a negative number is an error you'll hear about, instead of an imaginary number sneaking into a student's problem.

{% endset %} {% set tip_case %}

Tick when capital letters matter, e.g. chemical symbols (Co is cobalt, CO is carbon monoxide).

{% endset %} {% set tip_notes %}

Your marking guide: what a full-credit answer includes, common mistakes, how much each part is worth.

Only you see it, next to each student's essay while you grade.

{% endset %} {% set tip_pictures %}

One picture: every student sees it.

Several: each student gets one at random. Give them labels (cat, dog…) and use [picture] in the question or answer to mean “the label of the picture this student got”.

{% endset %} {% set tip_calc %}

A note about this problem. It shows in your problem list, and the quiz builder warns you if you put it in a quiz marked “no calculator”.

Students see the quiz's own calculator setting.
